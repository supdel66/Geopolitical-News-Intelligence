# Geopolitical News Pipeline / WW3 Context Analyzer

An automated, end-to-end Python pipeline designed to scrape, store, embed, and analyze geopolitical news articles with a specific focus on global conflicts and escalation themes.

## Features

1.  **Multi-Source RSS & API Scraping**
    *   Scrapes global news from BBC, CNN, Al Jazeera, Guardian, AP, NYT, and more.
    *   Integrates with NewsAPI to fetch articles based on custom geopolitical queries.
    *   Automatically filters articles using a predefined dictionary of high-risk keywords (e.g., "escalation", "missile", "gaza", "nato article 5").
    *   Extracts full text and image URLs dynamically using `BeautifulSoup`.

2.  **Dual Database Storage**
    *   **SQLite Tabular Storage**: Safely persists scraped metadata (Title, Content, Source, Dates, Images) using `INSERT OR IGNORE` to prevent duplicates.
    *   **ChromaDB Vector Embeddings**: Uses a local Ollama instance (`nomic-embed-text`) to chunk and mathematically embed article text for advanced semantic querying.

3.  **Advanced Exploratory Data Analysis (EDA)**
    *   **SQLite Analytics**: Generates distributions for Top Sources, High-Risk Keyword frequencies, and Article Length metrics using `seaborn` and `matplotlib`.
    *   **Semantic Vector Analytics**: Groups unstructured data into thematic clusters (e.g., "US-Israel", "Global Economy & Oil") and calculates average semantic distances/relevancy using ChromaDB.

4.  **Automated Dashboard Generation**
    *   Compiles all statistical results and generated PNG charts into a fully responsive, dark-themed HTML dashboard (`eda_output/report.html`).

## Prerequisites

Before running this pipeline, ensure `Python 3.10+` is installed along with the Ollama local AI runtime.

### 1. Install Dependencies

Install the required Python packages using `pip`:

```bash
pip install -r requirements.txt
```

*(Dependencies include: `requests`, `feedparser`, `beautifulsoup4`, `pandas`, `matplotlib`, `seaborn`, `chromadb`, and `ollama`)*

### 2. Install and Run Ollama

This project requires a local vector embedding model.
1. Download [Ollama](https://ollama.com/).
2. Pull the embedding model used in the vector database:
   ```bash
   ollama pull nomic-embed-text
   ```
3. Ensure the Ollama service is running in the background before starting the pipeline.

## Project Structure

```text
.
├── main.py                    # The central execution script tying all modules together
├── requirements.txt           # Python package dependencies
├── scraper/
│   └── scraper.py             # RSS & NewsAPI fetching and Beautifulsoup parsing logic
├── database/
│   ├── db.py                  # SQLite initialization and CRUD operations
│   └── vector_db.py           # ChromaDB initialization, Ollama chunking, and upserting logic
├── eda_code/
│   ├── eda.py                 # Tabular analysis and bar/histogram generation
│   ├── vector_eda.py          # Semantic clustering queries using ChromaDB
│   └── report_generator.py    # Builds the final HTML dashboard
├── sqlite_databases/          # Auto-generated by db.py (Contains news.db)
├── chromadb/                  # Auto-generated by vector_db.py (Persistent local vector storage)
└── eda_output/                # Auto-generated. Contains .png charts and the final report.html
```

## How to Run

Execute the main pipeline script. It will sequentially perform the scraping, database saving, vector embedding, and report generation processes:

```bash
python main.py
```

*Note: Depending on the volume of articles scraped, the ChromaDB chunking and embedding phase (`nomic-embed-text`) may take a few minutes.*

### Viewing the Results

Once `main.py` finishes execution:
1. Navigate to the `eda_output/` folder.
2. Open `report.html` in your preferred web browser to view the interactive dashboard.
